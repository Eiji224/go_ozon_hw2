# ДЗ 4: SQL и базы данных

В этой работе тренируем SQL: фильтрацию, агрегации, сортировку и джоины.
Все задачи решаются чистым SQL — писать Go-код пока не нужно (бонус в конце).

## Подготовка

Дальше по задачам используется такая схема (PostgreSQL):

```sql
CREATE TABLE users (
    id   BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    age  INT NOT NULL,
    city TEXT NOT NULL
);

CREATE TABLE orders (
    id      BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users (id),
    item    TEXT NOT NULL,
    price   INT NOT NULL
);
```

Тестовые данные:

```sql
INSERT INTO users (name, age, city) VALUES
    ('Анна',  25, 'Москва'),
    ('Борис', 40, 'Москва'),
    ('Вера',  40, 'Москва'),
    ('Глеб',  31, 'Казань'),
    ('Дина',  19, 'Казань'),
    ('Егор',  27, 'СПб');

INSERT INTO orders (user_id, item, price) VALUES
    (1, 'телефон', 50000),
    (1, 'чехол',   1500),
    (2, 'ноутбук', 120000),
    (4, 'телефон', 45000),
    (4, 'наушники', 12000),
    (6, 'наушники', 20000),
    (6, 'наушники', 18000);
-- у Веры (3) и Дины (5) заказов нет
```

## Задача 1: Долгожитель

Найдите **самого старого пользователя из Москвы**. Выведите его имя и возраст.

Подумайте: что выведет ваш запрос, если самых старых несколько? (В данных выше
такой случай есть — проверьте на нём.)

---

## Задача 2: Перепись населения

Посчитайте **количество пользователей по городам**. Выведите только те города,
где больше одного пользователя, и отсортируйте результат по количеству
по убыванию (при равенстве — по названию города по алфавиту).

Ожидаемый результат: Москва — 3, Казань — 2.

---

## Задача 3: Учёт трат

Для **каждого пользователя** посчитайте суммарную стоимость его заказов.
Выведите имя и сумму, отсортируйте по сумме по убыванию.

Важно: пользователи без заказов не должны потеряться — у них в колонке суммы
должен быть `0`, а не пустая строка и не пропущенная строка.

Ожидаемый результат: Борис — 120000, Глеб — 57000, Анна — 51500,
Егор — 38000, Вера — 0, Дина — 0.

---

## Задача 4: Любители музыки

Выведите **имена пользователей, которые покупали наушники**, без повторов,
отсортировав по имени. Важное условие: у пользователя может быть несколько
заказов с наушниками, но в результате его имя должно встретиться один раз.

Ожидаемый результат: Глеб, Егор.

---

## Задача 5: Бюджетный выбор

Выведите **название товара и цену самого дешёвого заказа** среди всех заказов
дороже 10000 рублей. Если таких заказов (с минимальной ценой) несколько —
выведите все.

Ожидаемый результат: наушники — 12000.
